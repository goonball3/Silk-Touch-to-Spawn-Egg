# Silk Touch to Spawn Egg

A Fabric mod for Minecraft 1.21.11 that allows you to obtain spawn eggs by killing mobs with a Silk Touch enchanted weapon.

## Features

- Kill mobs with Silk Touch to get their spawn eggs
- Configurable drop chance (0-100%)
- Can be toggled on/off via config
- In-game configuration via ModMenu (if installed)

## Installation

1. Install [Fabric Loader](https://fabricmc.net/use/) 0.18.4 or higher
2. Install [Fabric API](https://modrinth.com/mod/fabric-api)
3. Download the latest release from the [Releases](https://github.com/goonball3/Silk-Touch-to-Spawn-Egg/releases) page
4. Place the mod JAR file in your `mods` folder

## Configuration

The mod creates a config file at `.minecraft/config/silk-touch-to-egg.json` with the following options:

- `enabled`: Enable/disable the mod (default: `true`)
- `chance`: Drop chance percentage from 0-100 (default: `1`)

You can also configure these settings in-game if you have [ModMenu](https://modrinth.com/mod/modmenu) installed.

## Requirements

- Minecraft 1.21.11
- Fabric Loader >= 0.18.4
- Fabric API
- Java 21 or higher
